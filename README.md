# Shakki ♟️

ターン制のないチェスゲーム。

「Shakki」はフィンランド語で「チェス」を意味します。本作は従来のチェスと異なり、**ターンの概念がありません**。両プレイヤーが同時かつリアルタイムに自分の駒を操作でき、戦略と反応速度を競い合います。

> **着想元**：『ノーゲーム・ノーライフ』における機凱種（エクスマキナ）との決戦。盤上の駒がターンの枠を越え、自らの意思でリアルタイムに動き合う戦争へと変貌していくあの一戦から、本作の「ノンターン制チェス」という発想が生まれました。

## 特徴

- **ノンターン制**：相手を待つ必要がなく、両者が同時に操作するスピーディな対戦。
- **ローカル2人対戦**：1台のデバイスで、それぞれのキー操作で対局します。
- **チェスのルールに対応**：キャスリング（王車交代）やポーンのプロモーション（昇格）に対応。
- **エフェクトマス**：盤上にランダムで特殊なマスが出現し、踏むと数秒間**相手の操作方向が反転**します。
- **勝利条件の切り替え**：
  - 通常モード：相手の駒をすべて取れば勝利。
  - キングキルモード（Kill King Win）：相手のキングを取れば勝利。
- **キーのカスタマイズ**：各プレイヤーが操作キーを自由に再設定でき、設定は自動保存されます。
- **BGM・効果音**：BGM と効果音（SE）の音量・ミュートを個別に調整可能。

## 操作方法

各プレイヤーは独立したキーセットを持ちます。以下はデフォルト設定で、ゲーム内のオプションから自由に再割り当てできます：

| 操作                      | プレイヤー1（P1） | プレイヤー2（P2） |
| ------------------------- | ----------------- | ----------------- |
| 移動（選択枠）            | `W` `A` `S` `D`   | `↑` `↓` `←` `→`   |
| 決定・移動（Confirm）     | `G`               | `1`               |
| キャンセル（Cancel）      | `H`               | `2`               |
| キングへ戻る（Back King） | `Space`           | `0`               |

- ゲーム中に `Esc` でポーズ画面を開けます。
- 駒の操作は基本的に通常のチェスと同じです（キャスリングにも対応）。
- ポーンが最奥まで進むと、自動的に**クイーンに昇格（プロモーション）**します。
- メインメニューの **<ヒント（小提示）>** にゲームのコツが掲載されています。

> エフェクトマスを踏むと、相手の方向キーと決定／キャンセルキーが 5〜10 秒間反転します。

## 開発環境

- **エンジン**：Unity `2022.1.20f1`
- **言語**：C#
- **入力システム**：Unity Input System（キーの再割り当てに対応）

## プロジェクト構成

```
Assets/
├── Scenes/            # ゲームシーン（Shakki.unity）
├── Scripts/
│   ├── Game/          # 盤面と駒のロジック
│   │   ├── BoardManager.cs   # 盤面の状態、移動ルール、勝敗判定、エフェクトマス
│   │   ├── Board.cs          # 盤面の描画と座標変換
│   │   ├── Controler.cs      # プレイヤー操作、選択と着手の計算
│   │   └── Rebind.cs         # キーの再割り当て
│   └── UI/            # メニュー、設定、リザルトなどの画面
├── Resources/         # 駒の Prefab、Sprite、音声などの実行時リソース
└── Font/              # TextMesh Pro フォント
```

## 実行方法

### 1. ビルド済みファイルをダウンロード（おすすめ）

[GitHub の Releases](https://github.com/vaz1306011/Shakki/releases) からビルド済みのファイルをダウンロードし、解凍して `Shakki.exe` を実行するだけで遊べます。Unity のインストールは不要です。

### 2. Unity エディターから実行

1. Unity Hub で `2022.1.20f1` バージョンのエディターをインストールします。
2. そのバージョンで本プロジェクトを開きます。
3. Unity エディターで `Assets/Scenes/Shakki.unity` を開きます。
4. Play ボタンを押すとゲームが始まります。

## 設定の保存先

プレイヤーの設定（音量、キングキルモードの ON/OFF、キー割り当てなど）は以下に保存されます：

```
C:\Users\<ユーザー名>\AppData\LocalLow\Shakki\Shakki
```
